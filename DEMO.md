# BLUFF — Demo Kit

## 45-second screen-recording script

Have the app open at **http://localhost:5173**. For the most dramatic take, run
with `ANTHROPIC_API_KEY` set so the monologues are genuine Claude Fable 5
reasoning — but the script also works in offline mode, where the match *opens* on
a hand-authored stone-cold bluff, which is perfect for a first take.

Before recording: pick **Doyle** vs **Zoe** on the setup screen (or hit
**⟲ Randomize**), record at **1600×950+** so both thought panels and the table
are in frame, and set speed to **2×**.

| Time | Action | What the viewer sees |
| --- | --- | --- |
| **0:00–0:05** | Start on the setup screen. Read the tagline aloud, click **Start the match**. | The BLUFF title, two personas facing off, then the felt table lights up and cards deal in. |
| **0:05–0:12** | Let the first hand play. Point at the two glass panels. | Both agents' inner monologues type out in real time — one plotting a bluff, the other talking itself into a call. The audience is reading minds. |
| **0:12–0:20** | Say: "Neither of them can see the other's cards." Click **🛡 AUDIT**. | The audit viewer: **NO LEAKS DETECTED**, every payload showing the opponent's hidden cards flagged "must be absent." Close it. |
| **0:20–0:30** | Turn on **📺 COMM**, hit **2×**, and let a big pot build. | Chips pile up, the pot counter climbs. On the turn/river the panels diverge — the bluffer's story hardens, the caller gets nervous. A commentator line drops after the pot. |
| **0:30–0:38** | Wait for an **all-in** (or let the scripted opening reach its river shove). | The screen dims, a heartbeat kicks in, both thought panels lock. "ALL IN — the table holds its breath." |
| **0:38–0:45** | Hold on the showdown / fold. | The verdict banner slams down — **STONE COLD BLUFF: IT WORKED** — the pot slides to the winner, and the stats strip ticks the bluff into "worked." Fade out on the banner. |

**Director's notes**
- If you want a *guaranteed* bluff on camera, run with **no** API key: the match
  opens on the scripted classic — Doyle three-barrels 7♠2♦ (seven-high) and
  shoves the river; Zoe folds top pair; **STONE COLD BLUFF: IT WORKED**.
- **⧉ REPLAY** after any big hand is great B-roll: each monologue sits beside the
  action it produced, bluffs and correct/incorrect reads flagged.
- Let a match run to a bust for the end screen — the stack-size chart crossing
  over is a clean closing shot.
